# Windows private connection bootstrap
Run `VIVIM-ARBOR.cmd -Prepare` to download and verify the pinned official v0.0.21 Windows x64 client and exercise the local health-only MCP handshake. The archive SHA-256 is pinned to the official GitHub release asset digest; the executable is checked against the verified ZIP. No remote polling in preflight.

Double-click `VIVIM-ARBOR.cmd` for a foreground connection. Requires Node and a provisioned OpenAI Secure MCP Tunnel. First launch prompts for its ID and a restricted runtime API key via hidden local input; only the ID is saved under LocalAppData. No key stored or logged by this script. Subsequent launches prompt for the key again. Create the tunnel and runtime key at https://platform.openai.com/settings/organization/tunnels and https://platform.openai.com/settings/organization/api-keys. Confirm linked ChatGPT workspace and Tunnels Read/Use. Never use an admin key.

Once running, inspect the local health URL file and /readyz, then connect the exact tunnel in ChatGPT Plugins and call vivim_tunnel_health. A local preflight does not establish live connectivity. The only exposed tool in this bootstrap is a harmless health probe. Do not enable Host discovery until remote authentication and authorization are verified. Ctrl+C stops the foreground agent. Do not run duplicate instances. No autostart or provider inference configured. Costs and entitlement are not presumed. Official docs: https://github.com/openai/tunnel-client/blob/master/docs/onboarding.md .
