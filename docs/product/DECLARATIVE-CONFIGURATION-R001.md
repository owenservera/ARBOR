# Declarative configuration R001
First source implementation for the system-wide configuration authority. Shared Rust registry in core/programmability/src/configuration.rs and configuration.v1.json. Metadata and values are declarative; future options should reuse existing adapters and generic controls. This is an initial choice-type registry, not yet a general typed Host mutation API.
GPUI dynamically generates menu visibility controls, persists overrides in existing desktop-preferences.json (v2, reads v1 privacy preference), keeps Settings reachable, and filters GPUI menu chrome. No permission changes. Experimental Win32 HMENU is not covered. Pending window and capability visibility descriptors are read-only metadata, not effective runtime settings. Chrome launch adapter, native process visibility, connector/service launch controls, per-capability visibility, Host persistence/CAS and same-surface physical phone acceptance remain outstanding. Pending options are not promises of platform support. Preserve production plugin, process ownership, diagnostics, consent, stop/reveal controls, and browser sign-in recovery. No changes to live runtime from this commit.
