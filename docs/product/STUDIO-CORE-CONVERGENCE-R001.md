## Decision
Studio is ARBOR's core external-software perception, reconstruction, capability learning and browser execution subsystem. VLANG/HQKG compile internal software meaning; Studio provides observed external application meaning. Both feed existing canonical semantic/knowledge/operation contracts, not a second graph or effect authority. Host is the sole product approval/effect authority, and the existing Studio conversation runtime is its single browser actuator and send journal owner; never add another CDP actor. Native GPUI is the only product renderer; PWA is its authenticated remote viewport. Dedicated signed-in Chrome, no provider APIs or Playwright/Puppeteer. VIVIM-native workstation operations complement Studio, not replace it. Rust first for pure computation and validated contracts; retain working Node/CDP/local storage adapters until proven equivalent native replacements. Core is a dependency/lifecycle/contract designation, not a directory rename or a requirement for a single OS process.

## Source-grounded gaps (not speculative maturity percentages)

Verify source-pinned service manifest, exact installed version and isolated cold boot. Keep journal, sessions, profile and rollback.
2. Authority audit: atom-dispatch.runAtom accepts an attached page and execute flag for non-read atoms; this is a low-level primitive guard, not a Host approval. Audit real call graph and input classification, including developer CLI/MCP/harness routes. Do not interpret it as an established remotely reachable exploit. Prove no caller can mint authority or bypass existing Host approval and exact binding. Raw evaluation, cookie/storage and arbitrary browser controls stay internal; never expose them to general agents.
3. Semantic gap: Universal API explicitly does not attest per-action HQ identity. Bind real source/adapter/version/operation/typed input-output/effect/target/grant/readiness/evidence to existing identities. Keep declared, observed, verified, stale and unknown separate; capability discovery does not confer authority.
4. Distinguish developer public first-party code/evidence from user-local personal World. Reuse native web-memory and scoped graph only for compatible metadata, not indiscriminate private content.

Real independent capture provenance, no synthetic promotion, drift/replay/holdout/CAS/rollback acceptance. Learned actions may only propose typed inert plans; enable explicit new verified Host bindings separately.

8. Single UI: CLI no dashboard; server legacy routes remain; migrate needed views into current GPUI controls/read models; PWA only remote GPUI viewport. Preserve migration/recovery access until proven replacement. Retire legacy routes/assets deliberately, do not delete browser engine or data.
