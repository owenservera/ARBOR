# VIVIM + HQ glossary

HQ uses the VIVIM vocabulary on every owner-facing surface. Engineering
documents keep the precise internal term. Both are listed here.

| You see | Internal | Meaning |
| --- | --- | --- |
| My World | world — workspace registry + local index | workspace registry + local index |
| Space | space — registered project | registered project |
| My Agent | personalAgent — owner-scoped agent surface | owner-scoped agent surface |
| My AI Team | fleet — registered agent roster | registered agent roster |
| Team Session | swarm — parallel agent session | parallel agent session |
| Specialty | role — agent specialty | agent specialty |
| Agent DNA | genome — agent manifest (references only, never credentials) | agent manifest (references only, never credentials) |
| Memory | memory — notes table with tiers + provenance | notes table with tiers + provenance |
| Task | work — task / handoff bundle | task / handoff bundle |
| Progress Report | sitrep — brief | brief |
| Ability | capability — CLI command or MCP tool | CLI command or MCP tool |
| Permissions | authority — scope + approval boundary | scope + approval boundary |
| Activity Record | evidence — receipts ledger | receipts ledger |
| Discover | aperture — context bundle | context bundle |
| Build | forge — wiki generation | wiki generation |
| VIVIM on my computer | host — local HQ runtime | local HQ runtime |
| Advanced panel | studio — CLI | CLI |
| Phone Connection | bridge — MCP / CLI transport | MCP / CLI transport |
| Context | context — context | context |
| Map | index — index | index |

## Memory tiers

| You see | Internal | Promotion |
| --- | --- | --- |
| Recent | now | free to add |
| Saved Knowledge | later | reviewed |
| Core Memory | canon | owner confirmation required |

## Invariants

- Memory is not authority.
- Capability is not authorization.
- Evidence is not inference.
- One effect owner.
- No silent sends.
- Journal before effect.
- Owner confirmation for Core Memory.
